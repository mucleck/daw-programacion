## Crear nuevo proyecto Java

Usar los comandos disponibles en commands.sh para crear un  proyecto con maven  
(En un futuro con Gradle si eso)

Para:

- crear un proyecto en una ruta ./commands.sh createProject RUTA
- ejecutar la clase principal de un proyecto ./commands.sh run RUTA
